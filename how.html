How It Works

从 Python 描述到可运行的互联网

SEED Emulator 将“实验组合”与“底层运行”分离：用户负责用组件库描述互联网，编译器负责生成容器文件，再由 Docker 或 Kubernetes 承载运行。

💻

1. 编程描述

使用 Python 创建自治系统、网络、主机、路由器、IXP、BGP 对等关系和服务组件。

🔗

2. 分层融合

基础拓扑层、路由层和服务层通过 binding 机制融合，形成完整仿真实例。

📦

3. 编译输出

编译器生成 Docker Compose 或 Kubernetes 所需的运行文件和容器配置。

▶

4. 运行观察

启动容器后形成一个小型互联网，并可通过可视化界面观察数据包流向和事件过程。
