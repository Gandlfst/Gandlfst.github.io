Run real blockchain software on top of an emulated Internet. A controlled network makes it possible to explore how blockchain nodes communicate and how transactions and smart contracts behave.

The SEED blockchain labs provide practical exercises for blockchain exploration, smart contracts, and security. The materials below connect the emulator with these hands-on learning activities.
