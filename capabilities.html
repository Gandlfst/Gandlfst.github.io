Core Capabilities

从基础互联网到复杂服务生态

SEED Emulator 覆盖互联网基础设施、路由与命名体系、应用服务、攻击场景和容器化运行环境，让实验从“拓扑描述”走向“可启动、可交互、可复现”的小型互联网。

🌐

模拟 10,000 个路由节点的互联网级实验环境

在真实 AS 关系、PeeringDB 等数据集基础上生成大规模拓扑，并在单机或多机环境中运行仿真。

真实数据驱动：AS 关系、PeeringDB 等数据集
规模能力展示：单机运行万级路由节点
扩展方向：通过 Kubernetes 实现多机联合仿真

Capability Matrix

覆盖从基础设施到攻防实验的完整链路

🧭

互联网骨架建模

通过 AS、IXP、网络、主机、路由器和 BGP peer 构造互联网级结构，而不是只画单一局域网拓扑。

🧠

路由与命名体系

支持 BGP 路由传播、互联网交换中心互联、DNS 基础设施搭建，适合观察跨域网络行为。

🧪

安全实验承载

能够复现 BGP 劫持、Morris Worm、Botnet、暗网通信等实验，让攻击链路可控、可观察。

⛓️

真实应用生态

在仿真互联网中运行真实软件和服务，例如 Web、DNS、以太坊、门罗币与智能合约工具链。

📦

容器化部署输出

实验脚本编译后生成容器文件，既能在单机上快速运行，也能扩展到 Kubernetes 环境。

🔁

可复现与可扩展

实验环境由代码描述，便于课程发布、科研复验、参数调整和复杂场景的持续迭代。

Experiment Workflow

从实验想法到运行环境，一条链路完成

01

定义互联网

用 Python 创建 AS、网络、主机、路由器和互联网交换中心。

02

叠加服务

绑定 DNS、Web、区块链、Botnet、Darknet 等服务和实验角色。

03

生成运行文件

编译成 Docker Compose 或 Kubernetes 所需的目录、镜像和配置。

04

启动与观察

运行容器后形成小型互联网，用于教学演示、攻防复现和科研验证。

⛓️

真实软件参与仿真

区块链场景运行的是真实软件，而不是只做协议层抽象。以太坊、门罗币等系统可以部署在仿真互联网中。
